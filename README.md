# Mohanad Ahmed Bahaa: Portfolio

My personal portfolio site, where I show who I am, my skills, and the full stack projects I'm building.

🔗 **Live:** https://myportofolio-99a96.web.app

## Built with
- HTML5 (semantic markup)
- CSS3 (custom properties, Flexbox, Grid, media queries, animations)
- Vanilla JavaScript (DOM, events, `localStorage`, `IntersectionObserver`)
- Firebase Hosting

## Features
- Dark and light mode, remembered between visits
- Responsive layout with a mobile menu
- Scroll-reveal animations, turned off for users who prefer reduced motion
- Project cards with a mouse-follow glow effect
- Accessible: semantic HTML, keyboard focus styles, ARIA labels

## Project structure
```
public/
  index.html    page content
  style.css     all styles
  script.js     theme toggle, mobile menu, animations
  404.html      page-not-found page
firebase.json   hosting config
```

## Run locally
Clone the repo and open `public/index.html` in your browser. No build step needed.

```bash
git clone https://github.com/mohanadahmedbahaa-ctrl/portfolio.git
```

## Deploy
```bash
firebase deploy
```
